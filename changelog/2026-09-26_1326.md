# Cleanup pass + profile photo resize

**2026-09-26 13:26**

First maintenance pass on the static site. Goal was to strip the artifacts left
over from the old four-service architecture, fix what was visibly broken in
production, and scale up the profile photo.

`npm run build` and `npm run lint` both pass.

## Changed

### Profile photo — 1.5x
`src/components/AboutSection.tsx`

- `h-32 w-32` -> `h-48 w-48` (128px -> 192px)
- `sm:h-40 sm:w-40` -> `sm:h-60 sm:w-60` (160px -> 240px)

Not visually verified — the Chrome extension was not connected during this
session, so there is no screenshot. The Tailwind values are exact 1.5x
multiples and the build is clean, but the desktop size is worth an eyeball
since the photo now sits against a `max-w-3xl` bio column.

### Favicon — 633 KB -> 3.7 KB
`public/favicon.svg` (pending removal) -> `public/favicon.png`

The old favicon was a 1254x1254 RGB PNG base64-encoded inside an Inkscape SVG,
carrying full `sodipodi:`/`inkscape:` editor metadata. It was the single
largest asset on the site — larger than the resume PDF.

The "AS" monogram artwork was preserved rather than redrawn: the embedded
raster was extracted, box-downsampled to 180x180, and re-encoded as 8-bit
grayscale (lossless in practice — the mark is white on flat black). Box filter
was chosen over bilinear because the source is ~10x the target and bilinear
aliases the thin script strokes.

Done with a throwaway PNG decoder/encoder built on node's built-in `zlib`. No
new dependencies were added. 180x180 serves as both `icon` and
`apple-touch-icon`.

### Meta tags
`index.html`

Was `<title>Portfolio</title>` and nothing else — every shared link previewed
as a blank card. Added: real title, description, author, `theme-color`,
OpenGraph, and Twitter card tags.

`og:image` and `og:url` are currently root-relative. Scrapers resolve those
inconsistently, so they need to become absolute URLs once the site is on its
final domain. There is a comment in `index.html` marking this.

Separately, `websitepic1.jpg` is square, so previews render as a small square
rather than a wide banner. A dedicated 1200x630 OG image is a later
nice-to-have.

### Removed the broken PSoC6 project card
`src/content/projects.ts`

The entry was shipping the literal string `TODO: add a description.` next to an
`imageUrl` pointing at a file that does not exist, so the live site rendered a
broken-image icon beside the word TODO.

Pulled from the array. Both repo URLs are preserved in a comment at the top of
the file so it can be restored once it has real copy and a screenshot.

### Stale references to the deleted backend
Three comments still described an architecture that no longer exists:

- `src/content/profile.ts` — "project data comes from the backend/database,
  not a frontend constant", sitting directly beside `projects.ts`
- `src/content/projects.ts` — a 12-line TODO instruction manual as the file header
- `src/components/ProjectsPlaceholder.tsx` — user-facing copy reading
  "populated from the backend once there's a project worth showing"

### Dev server config
`vite.config.ts`

Dropped `server.host` and `server.watch.usePolling`, plus their comments about
Docker Desktop bind mounts and container networking. There is no container
anymore; `usePolling: true` was only costing dev-server performance.

## Fixed

### Nav drawer links were focusable while closed
`src/components/NavDrawer.tsx`

The drawer used `opacity-0 pointer-events-none` when closed, which hides it
visually but leaves its four links in the tab order — keyboard users tabbed
through invisible navigation. Added `inert={!open}` (natively supported in
React 19, typechecks clean) and `aria-controls` on the hamburger button.
